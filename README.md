🌦️ Weather App
A modern weather application built using React + Vite that fetches real-time weather data using the OpenWeather API.

🚀 Live Demo: https://myweather26.netlify.app/

🛠️ Tech Stack
React
Vite
JavaScript (ES6+)
OpenWeather API
CSS (Glassmorphism UI)

✨ Features
🔍 Search any city
🌡️ Real-time temperature data
💧 Humidity information
🌥️ Weather condition details
🎨 Modern glass UI design

🖥️ Run Locally
npm install
npm run dev

🏗️ Build for Production
npm run build
